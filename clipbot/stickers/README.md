# Emoji stickers

512 px emoji from Google's [Noto Emoji](https://github.com/googlefonts/noto-emoji) (`2D/png/512`),
named for what they say on a clip (`skull.png`, `mind-blown.png`, …). Noto Emoji's image resources are
under the Apache License 2.0 (`licenses/Apache-2.0.txt`); the project's own license file is in
`licenses/noto-emoji-LICENSE.txt`. The dashboard's Pictures tab offers them as stickers.
